- Contact uses teal panels, Night form inputs and delivery notice, Frost text, readable native dark controls, amber focus/error borders with existing inline error text. Preview, privacy and inactive-submission safeguards unchanged.
- Footer retains the approved Night/Frost presentation; hover/focus and mobile dropdown colors match the shared language. Decorative arrows match the homepage's supported right-arrow glyph. No new features, fonts, media or dependencies.
- Supporting routes receive only shared theme changes; their placeholder content and layout are not redesigned.
